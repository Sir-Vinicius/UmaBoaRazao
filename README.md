# Uma Boa Razão

**Uma Boa Razão** é um jogo narrativo de ação em perspectiva de primeira pessoa, desenvolvido na Unity. Acompanhamos Fabiano, um vaqueiro que atravessa o sertão em busca de sua cachorra, Baleia.

## Tecnologias utilizadas

- Unity 6.3 LTS
- C#
- Unity Input System
- FMOD Studio / FMOD for Unity

## Como jogar

**Página de publicação:** [Página do itch.io](https://lunesign.itch.io/uma-boa-razao)

## Como abrir o projeto na Unity

1. Clone ou baixe este repositório.
2. Abra o projeto utilizando o Unity Hub e uma versão compatível da Unity.
3. Aguarde a importação dos arquivos e pacotes.
4. Verifique as configurações e dependências necessárias, incluindo a integração com FMOD.
5. Abra a cena inicial do projeto e execute o jogo pelo Editor da Unity.

A execução pode depender de configurações adicionais e dos arquivos necessários para a integração de áudio.
